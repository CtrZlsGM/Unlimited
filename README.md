# Unlimited

**A free Windows toolkit for gamers.** Real display control, real system
optimization, real automation — without injection, without anti-cheat risk,
and without the ads and paywalls that plague this category.

Built for people who want more control over their setup and want to know
exactly what's happening under the hood.

---

## What it does

### 🎨 Display & Color
- **Color control** — gamma, brightness, contrast, and digital vibrance (NVAPI)
- **Curves editor** — per-channel RGB curves with live preview and drag handles
- **Resolution switching** — every mode your monitor supports, one click away
- **GPU scaling modes** — Stretched, Aspect, Centered, Native

### 🎯 In-Game Tools
- **Crosshair overlay** — click-through, topmost, hotkey-toggleable, fully customizable
- **Ping monitor** — live chart with min / avg / max / packet loss
- **Automation** — auto-apply a profile the moment a game launches

### ⚡ Performance
- **System booster** — 15+ real Windows tweaks with one-click backup and restore
- **Before/After metrics** — see exactly what changed: CPU, RAM, processes

### 🧩 Quality of Life
- **Profiles** — save and load your entire setup as a single config
- **Global hotkeys** — toggle any profile or overlay instantly
- **Discord Rich Presence** — show what you're doing
- **System tray** — runs quietly in the background, closes to tray
- **Modern UI** — Windows 11 native design with Mica backdrop

---

## Why it's safe

Every feature works at the **Windows system level**. Nothing ever touches a game.

- ✅ No DLL injection
- ✅ No game process memory access
- ✅ No hooks into DirectX, OpenGL, or any graphics pipeline
- ✅ Uses no techniques that anti-cheat systems flag
- ✅ No telemetry
- ✅ No hidden network calls
- ✅ No ads
- ✅ No paid tiers
- ✅ No account required

The booster only changes Windows settings. The crosshair is just a window
on your desktop. The color tools call the same Windows APIs the OS itself uses.

## Installation

1. Download `Unlimited.exe` from the [**Releases**](../../releases) page.
2. Run it. That's it — no installer, no setup wizard.
3. For full booster functionality, right-click → **Run as administrator**.

> **Antivirus notice:** Unlimited is unsigned, so Windows SmartScreen may
> show a warning on first launch. Click **More info** → **Run anyway**.
> The app is fully offline and open to inspection.
